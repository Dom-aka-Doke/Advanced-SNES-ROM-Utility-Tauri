## Advanced SNES ROM Utility JS v2.1.0

### New
- **Options menu** with *Reset Options* (moved from *Help*), *Scan ROM on loading* (in sync with the check box) and *Set Emulator…*
- **Run in Emulator** (<kbd>F5</kbd>, *File* menu) – starts the current state of the ROM, incl. unsaved changes, in your emulator
  - Windows: e.g. `snes9x-x64.exe` · macOS: e.g. `Snes9x.app` / `OpenEmu.app` · Linux: e.g. `snes9x-gtk`
  - Arguments with `%ROM%` placeholder (e.g. for RetroArch cores)
  - Runs a temporary copy – the original file stays untouched, save files of the emulator are kept

### Fixed
- **Saving** (*Save* / *Save As*) failed with "expected raw bytes" in v2.0.0
- ROM Heatmap: the bank tooltip had a transparent background – now semi-transparent white and readable

### Downloads
| System | File |
